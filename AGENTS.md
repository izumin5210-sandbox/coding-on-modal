# Project Steering Index

In this repository, the following three documents are treated as primary design references, similar to Kiro steering files.

- Product steering: `docs/product.md`
- Technical steering: `docs/tech.md`
- Structure steering: `docs/structure.md`

## Agent Rules
- Before starting any work related to requirements or implementation direction, review the three documents above.
- If requirements or technical decisions change, update the steering documents in the same PR as the code changes.
- Use `Session` for public-facing naming, and keep `Sandbox` limited to internal implementation context.
